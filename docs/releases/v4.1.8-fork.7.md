本版本增加作者翻译开关并修复署名偏移。请同时更新插件与 Python 服务端，重启翻译服务后从原 PDF 重新翻译。

### 更新内容

- PDF2zh 2.x 设置新增“翻译作者”，默认关闭。关闭时，识别出的首页作者行保留原文姓名、署名、字体和坐标，并跳过翻译及术语提取。
- 开启时，先合并同一行中相邻的作者片段，避免姓名被拆开翻译后重复补姓；单行中文作者行恢复原来的居中或左对齐位置及基线，独立作者列保留分开布局。
- 标题和摘要继续正常翻译。机构、地理信息、作者简介和正文中提及的人名不作为首页署名统一保留。

### 下载与安装

- [Zotero 插件（zotero-pdf-2-zh.xpi）](https://github.com/xiegaoxiao/zotero-pdf2zh/releases/download/v4.1.8-fork.7/zotero-pdf-2-zh.xpi)
- [Python 服务端（server.zip）](https://github.com/xiegaoxiao/zotero-pdf2zh/releases/download/v4.1.8-fork.7/server.zip)

在 Zotero 插件管理器中从文件安装 XPI；更新 `server` 目录时保留本地 `config` 和虚拟环境，随后重启服务。本项适用于托管的 `pdf2zh_next` 环境；旧译文不会自动改变。

通过 121 项服务端测试、39 项插件测试、格式和静态检查、TypeScript 构建。使用截图对应论文进行离线排版验证：关闭时作者行渲染像素与原 PDF 完全一致；开启时完整署名只有一个翻译输入，译文保持居中。排版验证使用固定译文，不调用翻译 API。

附件提供 `SHA256SUMS` 校验文件和自动更新清单，下载及更新链接均指向 `xiegaoxiao/zotero-pdf2zh`。保留原作者署名、插件 ID 与 AGPL-3.0 许可证。
