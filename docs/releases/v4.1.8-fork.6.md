本版本由 xiegaoxiao/zotero-pdf2zh 发布。请同时更新插件与 Python 服务端，并重启服务。

### 更新内容

- 智谱默认使用 `glm-4.5-flash` 和官方 API 地址，保留 `glm-4.7-flash` 选项；支持修正旧预设地址。
- 新建配置保留 Zhipu、DeepSeek、Chat Compatible；翻译服务只显示已激活的配置及内置 SiliconFlow Free。
- 增加通用“启用深度思考”开关，默认关闭（推荐），以及 API 连通性测试、完整错误提示和 OpenCode 会话头兼容。
- 翻译进度窗口可以关闭，关闭后后台继续；“取消本批次任务”停止对应翻译进程并跳过余下文件。
- 修复 PDF 首字下沉、小型大写字母残留、字重、图表刻度与斜角标签；默认保留参考文献原文，并缓存重复翻译的版面检测结果。

### 下载与安装

- [Zotero 插件（zotero-pdf-2-zh.xpi）](https://github.com/xiegaoxiao/zotero-pdf2zh/releases/download/v4.1.8-fork.6/zotero-pdf-2-zh.xpi)：在 Zotero 插件管理器中选择“从文件安装插件”。
- [Python 服务端（server.zip）](https://github.com/xiegaoxiao/zotero-pdf2zh/releases/download/v4.1.8-fork.6/server.zip)：解压后更新 `server` 目录，保留本地 `config` 和虚拟环境，重启服务。
- `SHA256SUMS` 提供附件校验值；`update.json` 与 `update-beta.json` 用于插件自动更新。

旧译文需从原 PDF 重新翻译才能应用排版修复。排版补丁适用于托管的 `pdf2zh_next` 环境。
