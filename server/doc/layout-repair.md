# PDF 排版与字体修复

适用于本项目托管的 `pdf2zh_next` Python 环境，已在 `pdf2zh-next 2.9.0 / BabelDOC 0.6.2` 验证。旧版 `pdf2zh 1.x` 和独立 Windows exe 不应用此补丁。

## 修复行为

- 合并同类、近乎完全包含且行高相近的重复文本检测框，减少单词被拆成多个段落的问题。保留相邻栏、公式框和多行段落中的短行。
- 在分段前去除同一位置、字体、字号、绘制样式和 XObject 中重复绘制的字形，避免图例多次翻译后重叠。
- 将正文开头的首字下沉单词规范为正文样式，避免剩余大写字母被当成公式。已有公式标记、正常首字母和上下标保持原有处理方式。
- 对可安全识别的跨页普通句子，先合并翻译再按首行宽度分配回两个输出位置。含公式或复杂混合样式的句子仍由原引擎处理。
- 对原本居中的多行标题，取消首行缩进，中文译文逐行居中；增加有条件的领域术语和标题句法提示。
- 从源 PDF 提取短小的 90°/270° 旋转英文标签，按原方向和实际字体宽度绘制译文。近白色多行模块标签为图标留出间距，新字体资源名称避免与旧子集冲突。仅处理可提取文字，不处理任意倾斜角度或图片内文字。
- 字体压缩时保留原有简单 TrueType 字体及其关联对象，避免稀疏 MacRoman cmap 重映射后出现“复制是 20，显示却是 43”的字形错误。其他字体仍进入原生压缩流程。
- 纯数字及数字标点序列（如 `50 80`）跳过翻译，保留其坐标、粗细与字号；含文字的轴标题和图注仍正常翻译。

## 应用方法

重启服务后，从原始 PDF 重新翻译。服务解析托管环境后检查补丁，重复调用不会叠加。引擎升级后，安装器检查源码插入点；不匹配时明确报错，避免盲目修改未知版本。

也可在 `server` 目录手动执行：

```sh
python -m utils.install_layout_repair
```

核心模块为 `utils/pdf_layout_repair.py`、`utils/rotated_labels.py` 和 `utils/safe_font_subset.py`；安装器为 `utils/install_layout_repair.py`，自动入口位于 `utils/venv.py`。安装器保留此前已有的自定义修改，并为修改过的引擎文件保存 `.before_zotero_layout_repair` 备份。

## 验证与限制

相关测试包括重复检测框、重复字形、首字下沉、标题居中、跨页句子、旋转标签、字体资源重名、纯数字序列和字体压缩后的视觉一致性。字体回归使用自行生成的合成字形 PDF，不包含个人论文或第三方字体数据。运行命令见仓库根目录的 `FORK_NOTES.md`。

本地端到端验证重译了完整 14 页文档并逐页渲染检查；首页 20、30、40、50、80 刻度与原图逐像素一致，旋转标签和图例数量检查通过。原文档、译文、服务配置及翻译日志不随源码分发。

补丁采用保守识别规则，不能替代人工校对；特别复杂的公式、图像内文字和不同引擎版本仍可能需要另外处理。
