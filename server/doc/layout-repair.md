# PDF 排版与字体修复

适用于本项目托管的 `pdf2zh_next` Python 环境，已在 `pdf2zh-next 2.9.0 / BabelDOC 0.6.2` 验证。旧版 `pdf2zh 1.x` 和独立 Windows exe 不应用此补丁。

## 修复行为

- 合并同类、近乎完全包含且行高相近的重复文本检测框，减少单词被拆成多个段落的问题。保留相邻栏、公式框和多行段落中的短行。
- 在分段前去除同一位置、字体、字号、绘制样式和 XObject 中重复绘制的字形，避免图例多次翻译后重叠。
- 将正文开头的首字下沉单词规范为正文样式与基线，避免剩余大写字母被当成公式。支持 TeX 常见的 80% 小型大写字母及两字母开头，并消除几何间距推断产生的词内空格。识别依据为段首位置、明显放大且下沉的首字、接近正文基线的词尾及字号，不使用论文标题或单词白名单。已有公式标记、正常首字母、独立标题和上下标保持原有处理方式。
- 对可安全识别的跨页普通句子，先合并翻译再按首行宽度分配回两个输出位置。含公式或复杂混合样式的句子仍由原引擎处理。
- 对原本居中的多行标题，取消首行缩进，中文译文逐行居中；增加有条件的领域术语和标题句法提示。
- 从源 PDF 提取短小的 90°/270° 旋转英文标签，按原方向和实际字体宽度绘制译文。近白色多行模块标签为图标留出间距，新字体资源名称避免与旧子集冲突。仅处理可提取文字，不处理图片内文字。
- 对引擎跳过的斜角短标签保留原文，按源 PDF 的字体编码恢复原有字形、角度、坐标、颜色与透明度，支持 Type3 自定义字体编码和 CID Unicode 编码。只导入缺失字形，已有字形不重复绘制，不复制周围图形或文字。斜角标签不发送给翻译接口。
- 字体压缩时保留原有简单 TrueType 字体及其关联对象，避免稀疏 MacRoman cmap 重映射后出现“复制是 20，显示却是 43”的字形错误。其他字体仍进入原生压缩流程。
- 纯数字及数字标点序列（如 `50 80`）跳过翻译，保留其坐标、粗细与字号；含文字的轴标题和图注仍正常翻译。
- 含源文字重变化的段落保留样式占位符，即使请求关闭富文本翻译，也保留普通字体与粗体的边界；跨页句子回填时沿用下一页原有的粗体标记，后续正文保持常规字重。含字重变化的长段落不因超过 40 个占位符而整段丢弃样式。字重未知或没有字重变化的段落沿用原设置；不支持 LLM 的翻译器沿用原引擎行为。

## 应用方法

重启服务后，从原始 PDF 重新翻译。服务解析托管环境后检查补丁，重复调用不会叠加。引擎升级后，安装器检查源码插入点；不匹配时明确报错，避免盲目修改未知版本。

也可在 `server` 目录手动执行：

```sh
python -m utils.install_layout_repair
```

核心模块为 `utils/pdf_layout_repair.py`、`utils/rotated_labels.py` 和 `utils/safe_font_subset.py`；安装器为 `utils/install_layout_repair.py`，自动入口位于 `utils/venv.py`。安装器保留此前已有的自定义修改，并为修改过的引擎文件保存 `.before_zotero_layout_repair` 备份。

## 验证与限制

2026-10-16：Xue 的 Vision Transformer with Attentive Pooling 论文中，首段 `FACIAL` 的首字为 27.6601 pt、词尾为 7.6 pt、正文为 9.5 pt。修复前词尾被公式检测器整体保留；修复后实际引擎解析与翻译输入均包含完整 `FACIAL expression`，公式中不再包含 `ACIAL`。使用固定中文译文通过引擎进行离线排版并渲染首段，首字与后续文字字号一致，位于“引言”下方，没有英文词尾残留。此验证检查排版，不调用 API，也不覆盖原 PDF 或已有译文。

相关测试包括重复检测框、重复字形、首字下沉、标题居中、跨页句子、旋转标签、字体资源重名、纯数字序列和字体压缩后的视觉一致性。字体回归使用自行生成的合成字形 PDF，不包含个人论文或第三方字体数据。运行命令见仓库根目录的 `FORK_NOTES.md`。

字重修复另有 5 项测试，覆盖两种粗细变化方向、常规及纯斜体段落、未知字体、空白字形与跨页样式回填。在保留 `--disable-rich-text-translate` 请求的条件下重译完整 14 页文档，跨页强调句前后均使用 `SourceHanSerifCN-Bold`，后续正文使用常规字体；逐页渲染及图表刻度、旋转标签回归检查通过。

本地端到端验证重译了完整 14 页文档并逐页渲染检查；首页 20、30、40、50、80 刻度与原图逐像素一致，旋转标签和图例数量检查通过。原文档、译文、服务配置及翻译日志不随源码分发。

补丁采用保守识别规则，不能替代人工校对；特别复杂的公式、图像内文字和不同引擎版本仍可能需要另外处理。

斜角标签新增 6 项回归测试，覆盖 Type3 自定义字符编码、CID 中文、不同角度、颜色与背景、部分字形已存在、重复运行及页码选择。实际页面翻译、字体压缩及保存后保留全部 14 个斜角轴标签；完整双语文档另外验证了 39 个标签恢复、原文侧和其他页面不变，以及标签区域的像素一致性。使用自行生成的合成 Type3 字形测试，不分发论文数据。

## 跨页长句衔接

相邻页正文跨页断句时，提取前页最后一个未结束句子和次页第一个句子合并翻译，前后的完整句子保留独立翻译输入。支持长段落、单句次页和两页不同的单一样式；引用占位符使用独立编号，回填时恢复各页原编号及样式。按源字形宽度和原句比例控制第一页容量，优先采用模型给出的自然短语断点。复杂混合样式或未知标签沿用引擎原有策略。

批量结果校验失败时恢复每段原始字符串，避免将整批字符串列表写入单个段落。新增 15 项跨页回归测试覆盖缩写、小数、引用编号与归属、样式跨句边界、断点选择及异常响应的原子校验，并验证补丁重复安装。
