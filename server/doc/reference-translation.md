# 参考文献翻译设置

插件设置的 `pdf2zh_next` 高级选项新增 **翻译参考文献（默认关闭）**。未勾选时，自动识别的参考文献区保留原文、字形、字号及坐标，正文仍正常翻译；勾选后，参考文献进入原有翻译流程。旧版客户端未传此设置时也默认保留参考文献原文。

需要配套使用本分支的插件、服务端及托管的 `pdf2zh_next` 环境。更新插件 XPI 并重启服务后，从原始 PDF 重新翻译；已有译文不会自动修改。独立 Windows EXE 与旧版 `pdf2zh` 引擎不支持此补丁。

## 识别范围

从独立的 `References`、`Bibliography`、`Works Cited`、`参考文献` 等标题，或引擎明确标注的参考文献块识别区域。按页面及分栏阅读顺序处理，支持参考文献在正文同页开始、跨栏和跨页延续；遇到附录、致谢或后续章节标题时恢复翻译。不会直接跳过末尾整页。保留段落同时跳过自动术语提取，避免将文献题名加入术语表。

无标题且未被版面模型识别的参考文献、仅翻译参考文献中间几页、图片中的文字，以及缺少清晰章节边界的复杂排版可能无法正确识别。该开关不等于“跳过最后几页”。

## 实现与验证

请求字段 `translateReferences` 默认 `false`。服务端通过本次子进程的环境变量 `ZOTERO_PDF2ZH_TRANSLATE_REFERENCES` 传递设置（`0` 保留原文，`1` 翻译），不修改服务器共享环境。PDF 结构修复后的重试沿用同一设置。

`utils/reference_filter.py` 在正文翻译与术语提取前标记保留段落；安装器同时兼容 LLM 与非 LLM 翻译路径。检测不调用翻译 API、不记录原始文献内容。

```sh
python -m unittest discover -s tests -p test_reference_filter.py -v
python -m unittest discover -s tests -p test_translation_output_isolation.py -v
```

测试覆盖默认值、显式开启、任务环境隔离、修复重试、双栏混排、跨页、附录边界、标题变体、误识别防护与原始样式保留。

已对一篇双栏论文的末两页进行端到端翻译与渲染验证：同页结论译为中文，左栏中部开始及后续整页的参考文献保持英文；参考文献区域的原文字形和位置保留。文献原文、译文、个人配置和运行日志不随源码分发。
