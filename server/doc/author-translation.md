# 作者翻译与署名位置

托管的 `pdf2zh_next` 环境支持“翻译作者”开关，默认关闭。插件通过请求字段 `translateAuthors` 传递选择，服务端将其写入本次翻译子进程的 `ZOTERO_PDF2ZH_TRANSLATE_AUTHORS` 环境变量。旧客户端缺少字段时按关闭处理；不会修改服务端共享环境。

关闭时，识别出的首页作者段落跳过 LLM、普通翻译和术语提取，源字形通过引擎原样传递。开启时，将同一基线的相邻片段合并成完整作者行后再翻译；单行中文译文恢复源行的水平对齐和基线。隔开的多列作者不合并，折行译文保留引擎的段落排版。

识别范围是首页标题与摘要或引言之间的独立署名块，并结合作者布局标签、姓名形态与坐标。机构、地理信息和正文中提及的人名不统一保留；作者与摘要混在同一个无法安全分离的段落时不强行拆分。此功能不推测译名，也不保证模型返回的人名音译准确。

核心模块为 `utils/author_filter.py`；`utils/install_layout_repair.py` 在样式识别之前安装署名识别与合并、普通翻译保留检查，以及排版后的作者对齐。已有安装可重复应用，补丁不叠加。

截图对应的 Xue 论文中，解析器将 `Fanglei Xue, Qiangchang` 与 `Wang, ...` 分成了两个独立输入。默认保留两块的原始字形与坐标；开启后改为同一完整作者行输入，避免模型分别处理姓名片段。离线首页面渲染确认：关闭时作者区域与原 PDF 像素一致；开启时只产生一个作者翻译输入，中文行的水平中心为 305.48 pt，原页面中心为 306 pt，基线保持原位。标题和摘要继续翻译，原 PDF 和旧译文保留。

更新后重启服务，从原 PDF 重新翻译。测试命令：

```sh
python -m unittest discover -s tests -p test_author_filter.py -v
```
